# Pitch Deck Generation Skill

## Purpose
Generate professional pitch decks for BeRight Protocol using AI-powered design tools.

## Available Tools

### 1. Canva MCP (Primary)
The Canva MCP server is configured in this project. Use it to:
- Create designs from templates
- Autofill pitch deck templates with BeRight content
- Export as PDF/images

**Trigger keywords for Canva MCP:**
- "create pitch deck"
- "design presentation"
- "export slides"

### 2. Gamma API (Alternative)
For bulk/automated generation, use the Gamma REST API.
- Requires Pro account ($15/mo)
- Best for mass personalization

## BeRight Pitch Deck Content

### Core Narrative
1. **Problem**: Prediction markets require manual research. Users lack time/expertise.
2. **Solution**: AI-powered prediction market intelligence that delivers alpha passively.
3. **How It Works**: Multi-agent system (Scout, Analyst, Trader) that researches, forecasts, and executes.
4. **Market**: $14B prediction markets + growing crypto/web3 adoption.
5. **Traction**: [Add metrics - users, forecasts, accuracy]
6. **Team**: [Add team backgrounds]
7. **Ask**: [Funding amount and use of funds]

### Key Differentiators
- AI does the work, not assists
- On-chain calibration scores (Solana)
- Multi-platform (Polymarket, Kalshi, MetaDAO)
- Real-time arbitrage detection

### Visual Assets Needed
- Agent architecture diagram
- User flow mockups
- Market size chart
- Traction metrics

## Workflow

1. **Content First**: Draft slide content in markdown
2. **Template Selection**: Choose Canva pitch deck template
3. **Autofill**: Use Canva MCP to populate template
4. **Iterate**: Refine design with prompts
5. **Export**: Generate PDF for sharing
