ACCOUNT STRUCTURES:
===================

1. ForecasterState (PDA: [b"forecaster", forecaster_pubkey])
   Size: 320 bytes
   Rent: ~0.003 SOL (~$0.40 one-time)
   Fields:
   - bump: u8
   - authority: Pubkey
   - total_predictions: u32
   - resolved_predictions: u32
   - cumulative_brier_score: f64
   - avg_brier_score: f64
   - cumulative_log_score: f64
   - avg_log_score: f64
   - correct_predictions: u32
   - accuracy: f64
   - markets_traded: u16
   - best_category: u8
   - worst_category: u8
   - streak_correct: u16
   - max_streak_correct: u16
   - last_prediction_ts: i64
   - created_at: i64
   - calibration_buckets: [[u16; 2]; 10]
   - version: u8
   - _reserved: [u8; 64]

2. PredictionRecord (PDA: [b"prediction", forecaster_pubkey, market_id, timestamp])
   Size: 200 bytes
   Rent: ~0.002 SOL (~$0.27 per prediction)
   Fields:
   - bump: u8
   - forecaster: Pubkey
   - market_id: [u8; 32]
   - predicted_probability: f64
   - direction: PredictionDirection (Yes/No)
   - committed_at: i64
   - resolved_at: Option<i64>
   - outcome: Option<bool>
   - brier_score: Option<f64>
   - log_score: Option<f64>
   - memo_tx_signature: [u8; 64]
   - category: u8
   - version: u8

INSTRUCTIONS:
=============

1. initialize_forecaster()
   Accounts: authority (signer), forecaster_state (init), system_program
   Creates ForecasterState PDA
   Emits: ForecasterInitialized

2. record_prediction(market_id, timestamp_seed, probability, direction, memo_tx, category)
   Accounts: authority (signer), forecaster_state (mut), prediction_record (init), system_program
   Creates PredictionRecord PDA
   Updates forecaster total_predictions
   Emits: PredictionRecorded

3. resolve_prediction(outcome)
   Accounts: authority (signer), forecaster_state (mut), prediction_record (mut)
   Calculates Brier + log scores
   Updates all forecaster stats
   Emits: PredictionResolved, CalibrationUpdated

EVENTS:
=======

1. ForecasterInitialized { forecaster, timestamp }
2. PredictionRecorded { forecaster, market_id, predicted_probability, direction, timestamp, total_predictions }
3. PredictionResolved { forecaster, market_id, outcome, brier_score, log_score, timestamp, resolved_predictions, avg_brier_score, accuracy }
4. CalibrationUpdated { forecaster, avg_brier_score, avg_log_score, accuracy, resolved_predictions, streak_correct }

CALIBRATION METRICS:
====================

Brier Score:
- Formula: (predicted_probability - actual_outcome)^2
- Range: 0.0 (perfect) to 1.0 (worst)
- Industry standard for forecast accuracy

Log Score:
- Formula: log2(p) if correct, log2(1-p) if wrong
- Heavily penalizes overconfidence
- Encourages well-calibrated probabilities

Calibration Buckets:
- 10 ranges: 0-10%, 10-20%, ..., 90-100%
- Tracks [count, sum_outcomes] per bucket
- Enables calibration curve analysis
