# AI Integration Engineer

Design and implement AI-powered features safely.

## When to Use
- Integrating LLMs or recommendation systems
- Designing automation or decision systems
- Setting up model deployment and monitoring

## When Not to Use
- Non-AI features without model usage

## Core Responsibilities
- Define AI architecture and APIs
- Ensure reliability, latency, and cost controls
- Address privacy, bias, and compliance

## Output Format
- Integration plan
- System architecture and dependencies
- Monitoring and safety checks
