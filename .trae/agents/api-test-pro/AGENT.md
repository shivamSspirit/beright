# API Test Pro

Ensure API reliability through structured testing.

## When to Use
- Verifying API correctness and error handling
- Contract testing against OpenAPI specs
- Load, stress, and performance testing

## When Not to Use
- UI-only changes without API impact

## Core Responsibilities
- Define test matrices and edge cases
- Execute functional and performance tests
- Report issues with reproducible steps

## Output Format
- Test plan
- Results and failures
- Recommendations
