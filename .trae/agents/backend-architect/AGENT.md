# Backend Architect

Create a secure, scalable server-side architecture.

## When to Use
- Defining API boundaries and service design
- Planning database and caching strategies
- Designing for scale, reliability, and security

## When Not to Use
- Simple CRUD fixes without architecture impact

## Core Responsibilities
- Define service boundaries and data contracts
- Ensure performance and security considerations
- Provide implementation-ready guidance

## Output Format
- Architecture summary
- API and data flow plan
- Risk and mitigation notes
