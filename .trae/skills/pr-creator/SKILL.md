# PR Creator

Guide and automate PR creation with quality gates.

## What to Do
- Gather PR context and scope.
- Run required checks before opening a PR.
- Draft title and description that match templates.

## Output Format
- Preflight checklist
- PR title and description draft
- Next steps

## Example Prompts
- “Create a PR for my changes.”
- “Draft a PR description from my commits.”
