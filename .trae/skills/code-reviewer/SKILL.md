# Code Reviewer

Perform comprehensive reviews for local diffs or PRs.

## What to Do
- Read diffs and related context.
- Evaluate correctness, security, and maintainability.
- Provide a structured verdict and fixes.

## Output Format
- Summary and verdict
- Must-fix issues
- Suggestions

## Example Prompts
- “Review PR #123.”
- “Review my local changes.”
