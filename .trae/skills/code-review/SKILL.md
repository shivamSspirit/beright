# Code Review

Deliver a focused review with actionable fixes.

## What to Do
- Check for correctness, edge cases, and regressions.
- Flag security and performance issues.
- Ensure style and conventions are followed.

## Output Format
- Summary
- Critical issues
- Recommended improvements

## Example Prompts
- “Review this PR.”
- “Audit this feature for bugs.”
