# Update Docs

Keep docs aligned with recent code changes.

## What to Do
- Identify impacted docs from code changes.
- Update existing docs or add new sections.
- Ensure examples and references remain accurate.

## Output Format
- Affected docs list
- Summary of updates
- Follow-up tasks

## Example Prompts
- “Update docs for this API change.”
- “What docs need edits for this PR?”
