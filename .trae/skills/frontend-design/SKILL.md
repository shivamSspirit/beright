# Frontend Design

Create bold, high-quality UI with a clear aesthetic direction.

## What to Do
- Choose an explicit visual style and apply it consistently.
- Prioritize typography, spacing, color, and motion.
- Avoid generic, low-contrast “AI-looking” layouts.

## Output Format
- Style intent and palette
- Component/page structure
- Implementation notes

## Example Prompts
- “Design a landing page with a retro style.”
- “Redesign this dashboard for a premium feel.”
