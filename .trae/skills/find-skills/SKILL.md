# Find Skills

Discover and install skills for specific tasks.

## What to Do
- Identify the domain or task area.
- Search for relevant skills by name or category.
- Install and confirm availability.

## Output Format
- Search terms used
- Skills found and selected
- Install results

## Example Prompts
- “Find skills for testing.”
- “Install a skill for API design.”
