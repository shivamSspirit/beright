# Frontend Code Review

Provide a structured review of UI code and patterns.

## What to Do
- Check correctness, state flow, and rendering behavior.
- Flag performance and accessibility concerns.
- Provide actionable fixes with file/line references.

## Output Format
- Summary
- Urgent issues
- Improvement suggestions

## Example Prompts
- “Review these React components.”
- “Audit this UI module before merge.”
