# Feature Builder

Build features from requirements through validation.

## What to Do
- Clarify scope, assumptions, and success criteria.
- Identify impacted files and services.
- Implement with tests and verify behavior.

## Output Format
- Feature plan
- Implementation summary
- Verification results

## Example Prompts
- “Add a new onboarding flow.”
- “Build a notifications feature.”
