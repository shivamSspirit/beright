# Webapp Testing

Create Playwright-based tests and diagnostic scripts.

## What to Do
- Identify key user flows to validate.
- Generate scripts for interaction and assertions.
- Capture screenshots and console logs if needed.

## Output Format
- Test plan
- Playwright script snippets
- Results summary

## Example Prompts
- “Test the login flow.”
- “Capture a screenshot of the dashboard.”
