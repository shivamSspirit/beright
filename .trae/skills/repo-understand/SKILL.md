# Repo Understand

Provide a concise, high-signal overview of a repository.

## What to Do
- Identify the product purpose and primary user flows.
- Summarize top-level directories and their responsibilities.
- Call out key entry points, critical services, and config.
- Mention testing, build, and lint commands if present.

## Output Format
- 1–2 paragraph summary
- Bulleted list of key directories
- Bulleted list of main flows and entry points

## Example Prompts
- “Give me a quick overview of this repo.”
- “Where should I start reading the code?”
