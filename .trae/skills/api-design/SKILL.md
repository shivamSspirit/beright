# API Design

Define clean, stable APIs with clear contracts.

## What to Do
- Define resources, endpoints, and verbs.
- Specify request/response schemas and errors.
- Include auth, pagination, and versioning strategy.

## Output Format
- API summary
- Endpoint list with schemas
- Example requests and responses

## Example Prompts
- “Design an API for notifications.”
- “Define endpoints for market data.”
