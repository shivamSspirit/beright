# Fix

Automate formatting and lint cleanup to keep CI green.

## What to Do
- Run formatting tools for modified files.
- Run lint checks and report remaining errors.
- Stop and summarize any manual fixes needed.

## Output Format
- Commands run
- Fixes applied
- Remaining issues

## Example Prompts
- “Fix lint errors.”
- “Run formatting and lint checks.”
