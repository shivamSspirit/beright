# Architecture Review

Review the architecture and suggest pragmatic improvements.

## What to Do
- Identify modules, boundaries, and dependencies.
- Highlight coupling, bottlenecks, and risky integrations.
- Suggest incremental improvements and sequencing.

## Output Format
- Summary of current architecture
- Risks and constraints
- 3–5 prioritized recommendations

## Example Prompts
- “Review the architecture and point out risks.”
- “How should we evolve this system?”
