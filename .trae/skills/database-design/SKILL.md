# Database Design

Create robust data models with clear access patterns.

## What to Do
- Identify entities, relationships, and constraints.
- Define indexes based on query patterns.
- Propose migrations and data backfills if needed.

## Output Format
- ER-style summary
- Schema definitions
- Index and migration plan

## Example Prompts
- “Design tables for user activity.”
- “Add a schema for audit logs.”
