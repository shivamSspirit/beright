## Slide 6: TECHNOLOGY

### **Multi-Agent Architecture**

**Headline:** "Four specialized agents. One unified system."

**Architecture:**
```
+-- Scout Agent (Fast)     -> Market scanning, arbitrage detection
|-- Analyst Agent (Deep)   -> Research, superforecaster analysis
|-- Trader Agent (Safe)    -> Execution with confirmation
+-- Orchestrator           -> Coordination, goal planning
```

**Tech Stack:**

| Layer | Technology |
|-------|------------|
| **AI** | Anthropic Claude (Opus for research, Sonnet for speed) |
| **Blockchain** | Solana (prediction commits via Memo Program) |
| **Data** | Real-time APIs from 5 platforms + Tavily search |
| **Database** | Supabase (PostgreSQL) + Upstash (Redis) |
| **Frontend** | Next.js + TailwindCSS |
| **Bot** | Telegram Bot API |

**Speaker Notes:**
> "BeRight isn't a simple chatbot. It's a multi-agent system where each agent has a specialized role. The Scout agent scans markets fast. The Analyst agent goes deep on research. The Trader agent executes safely. And the Orchestrator coordinates complex multi-step tasks. This architecture lets us balance speed and depth."
